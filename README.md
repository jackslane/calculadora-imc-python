# Calculadora de IMC em Python

Projeto desenvolvido durante o primeiro período de Análise e Desenvolvimento de Sistemas na CESAR School.

A aplicação recebe o peso e a altura do usuário, calcula o IMC e apresenta sua classificação.

## Funcionalidades

* Cálculo do IMC
* Classificação do resultado
* Validação de peso e altura
* Aceita números decimais com ponto ou vírgula
* Permite realizar novos cálculos sem reiniciar o programa
* Tratamento de entradas inválidas

## Como executar

Clone o repositório:

```bash
git clone https://github.com/jackslane/calculadora-imc-python
```

Entre na pasta:

```bash
cd calculadora-imc-python
```

Execute:

```bash
python main.py
```

## Exemplo

```text
========================================
BEM-VINDO À CALCULADORA DE IMC
========================================

Digite seu peso em kg: 70
Digite sua altura em metros: 1,70

Seu IMC é: 24.22
Classificação: Peso normal
```
